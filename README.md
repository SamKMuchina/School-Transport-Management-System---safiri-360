# Safiri360 - School Transport Management System

## Setup
1. Copy this folder into C:/xampp/htdocs/
2. Start Apache and MySQL in XAMPP
3. Open phpMyAdmin, create database "school_transport_db"
4. Import school_transport_db.sql (included in this repo)
5. Visit http://localhost/safiri360 in your browser
